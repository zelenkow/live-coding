# 003. Ограничение количества одновременных задач

## Условие

Есть список задач:

jobs = [
    ("task-1", 2),
    ("task-2", 1),
    ("task-3", 3),
    ("task-4", 2),
    ("task-5", 1),
]

Второе значение — время выполнения задачи.

## Нужно

1. Написать async-функцию `process_job(name, delay)`.
2. Одновременно должны выполняться максимум 2 задачи.
3. Для имитации работы использовать `asyncio.sleep()`.
4. При старте выводить: `task-1 started`
5. После завершения: `task-1 finished`
6. После выполнения всех задач: `All jobs completed`

## Использовать

- `asyncio`
- `asyncio.gather()`
- `asyncio.Semaphore`

## Дополнительно

Посчитать, сколько секунд заняло выполнение всех задач.
