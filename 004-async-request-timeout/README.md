# 004. Таймауты при асинхронных запросах

## Условие

Есть список "серверов":

servers = [
    ("server-1", 1),
    ("server-2", 5),
    ("server-3", 2),
    ("server-4", 4),
]

Второе значение — время ответа сервера.

## Нужно

1. Написать async-функцию `request_server(name, delay)`.
2. Ответ сервера имитировать через `asyncio.sleep(delay)`.
3. Все запросы запустить одновременно.
4. На каждый запрос установить timeout = 3 секунды.
5. Если сервер успел: `server-1 OK`
6. Если не успел: `server-2 TIMEOUT`
7. Программа не должна падать из-за timeout одного сервера.
8. В конце вывести: `Successful: 2`, `Failed: 2`

## Использовать

- `asyncio`
- `asyncio.gather()`
- `asyncio.wait_for()`

## Дополнительно

`request_server` должен возвращать `True` или `False`.
