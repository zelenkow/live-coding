# 002. Очередь задач для погодного сервиса

Использовать [Open-Meteo](https://open-meteo.com/).

## Схема БД

### cities

| Поле      |
|-----------|
| id        |
| name      |
| latitude  |
| longitude |

### weather

| Поле        |
|-------------|
| id          |
| city_id     |
| temperature |
| wind_speed  |
| created_at  |

## Нужно

1. Добавить минимум 5 городов в `cities`.
2. Прочитать города из БД.
3. Для каждого города создать задачу на получение погоды.
4. Положить задачи в `queue.Queue`.
5. Запустить 3 worker-потока.
6. Каждый worker:
   - берёт город из очереди;
   - делает запрос в Open-Meteo;
   - получает текущую температуру и скорость ветра;
   - сохраняет результат в таблицу `weather`.
7. Worker не должен завершаться из-за ошибки одного запроса.
8. После выполнения всех задач вывести последнее измерение для каждого города.
